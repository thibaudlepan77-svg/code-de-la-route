Les infractions qui retirent 4 points

Les infractions pour lesquelles le code de la route écrit une réduction de 4 points, relevées une par une dans son texte.

14articles du code de la route retirent 4 points, et les voici tous.

Chaque ligne reprend la phrase de l'article, telle qu'elle est écrite. Le retrait de points est prononcé par le même article, avec la formule réduction de quatre points du permis de conduire. Aucune de ces lignes n'est un résumé, vous pouvez toutes les vérifier au numéro indiqué.

Quand le législateur ouvre une énumération, sa phrase cesse d'être une phrase et devient une liste de cas. La citation s'arrête alors sur trois points, et la phrase entière se lit sur la page de l'article.

Le code de la route ne donne jamais un montant, il donne une classe de contravention. Les montants viennent d'ailleurs, et chacun porte son article. Le maximum encouru devant le tribunal est fixé par l'article 131-13 du code pénal. L'amende forfaitaire l'est par l'article R49 du code de procédure pénale, sa majoration par l'article R49-7 et sa minoration par l'article R49-9 du même code. Ce sont les seuls chiffres de ce site qui ne sont pas relevés dans le code de la route, et c'est pour ça qu'ils portent leur source ici.
