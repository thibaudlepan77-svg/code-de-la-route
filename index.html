Le code de la route, vérifié à l'article

Les chiffres du code de la route, repris un par un dans le texte qui les fonde. Aucun résumé, aucune reformulation, le numéro de l'article à chaque ligne.

852valeurs chiffrées relevées dans le code de la route, sur 271 articles.

Les sites de révision recopient des chiffres les uns sur les autres, et personne ne dit d'où ils viennent. Une valeur fausse se propage alors pendant des années sans que rien ne l'arrête. Ce site fait l'inverse. Chaque nombre est repris dans la phrase du code qui l'écrit, avec le numéro de l'article, pour que vous puissiez aller voir.

Le texte utilisé va jusqu'au 20 août 2026. C'est une borne, pas une formule. Une modification publiée après cette date n'est pas ici, et c'est écrit en bas de chaque page.
