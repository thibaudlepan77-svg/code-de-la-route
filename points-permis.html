Barème des points

Le barème des points du permis, article par article

Combien de points retire une infraction, et quel article l'écrit. Relevé dans le code de la route, sans reformulation.

42articles du code de la route prévoient une réduction de points.

Le nombre de points retirés circule partout, recopié de site en site, presque toujours sans l'article qui le fixe. Il se lit pourtant dans le code lui-même, à la fin de l'article qui décrit l'infraction, sous la formule donne lieu de plein droit à la réduction de trois points du permis de conduire. C'est cette phrase-là qui est relevée ici, article par article.

Par nombre de points

  • 6 points, 2 articles
  • 4 points, 14 articles
  • 3 points, 22 articles
  • 2 points, 3 articles

Les articles qui ne portent pas une seule valeur

Un article gradue parfois sa sanction selon la gravité du cas. Afficher pour lui un nombre unique donnerait un chiffre faux avec l'air d'être sourcé, ce qui est pire qu'un chiffre sans source. Ces articles sortent donc avec toutes leurs valeurs.

Le code de la route ne donne jamais un montant, il donne une classe de contravention. Les montants ci-dessus viennent d'ailleurs, l'amende forfaitaire de l'article R49 du code de procédure pénale et le maximum de l'article 131-13 du code pénal. Ce sont les seuls chiffres de ce site qui ne sont pas relevés dans le code de la route, et c'est pour ça qu'ils portent leur source ici.

Une famille de règles du code est hors du champ de ce site et n'apparaît donc dans aucun de ces tableaux, alors qu'elle retire elle aussi des points. Le barème ci-dessus est complet pour les quatorze familles publiées ici, pas pour le code entier.
