Le code de la route, relevé à l'article

Signalisation routiere

Toutes les valeurs chiffrées que le code de la route écrit sur ce sujet, reprises une par une dans la phrase qui les porte, avec le numéro de l'article. Rien n'est résumé, rien n'est arrondi.

33valeurs chiffrées sur ce sujet, réparties sur 23 articles du code.

La plupart portent sur classe, 21 des 33. Les manuels de révision les reformulent, ce qui suffit presque toujours et trompe le reste du temps. Ici la phrase est celle du code, vous pouvez la vérifier vous-même à l'article indiqué.
